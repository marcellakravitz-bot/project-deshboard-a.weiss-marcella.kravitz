כל הקוד של By Room נמצא בתיקייה הזו. הדשבורד (`index.html` בשורש) רק טוען את המודול ומפנה אליו מהקובייה.

## הדרך של קובץ

1. מנהל: העלאת תוכניות ← שם, קומה, מהדורה, תאריך, הערות ← גרירת הקבצים ← אישור הזיהוי ← העלאה.
2. לפני ההעלאה האתר מעתיק את רשימת האיפיונים המוגדרים (`byroom_marks`), כדי שהעיבוד ידע אילו קודים בתוכנית הם איפיונים.
3. הדפדפן מעלה ישירות ל-Google Cloud Storage, בחלקים של 16MB, עם המשכה אחרי ניתוק. DXF נדחס בדפדפן.
4. `byroom-admin` מפעיל את העובד ב-Cloud Run, קובץ אחד בכל הפעלה. העובד בודק טביעת אצבע וקורא את הקובץ.
5. כשכל קבצי הגרסה מוכנים, העובד מצליב ביניהם: ריצוף, חיפוי ותקרה כמו קודם, וכל איפיון מוגדר נוסף (נגרות, תאורה...) לפי מיקומו בחדר.
6. מנהל מסמן V ולוחץ "אישור שינויים מסומנים". רק `byroom_approve_items()` כותבת לנתונים המאושרים.
7. **פרסום ללקוח**: רק `byroom_publish()` מעבירה את המאושר ל-`byroom_published`, שממנו קוראים הלקוח והקישורים.
